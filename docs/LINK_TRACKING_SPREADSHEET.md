## STATUS LEGEND

```
TO DO = Not yet submitted
SUBMITTED = Submitted, waiting for approval
PENDING = In progress (email sent, awaiting response)
LIVE = Link is active and verified
PITCH = Pitch email sent to journalist
ORGANIC = Gained from community/content (no direct submission)
```

## GOOGLE SHEETS FORMULA (Optional)

**To auto-count "LIVE" links:**
```
=COUNTIF(G:G,"LIVE")
```

**To count by source (example: Bizna):**
```
=COUNTIF(B:B,"Bizna")*COUNTIF(G:G,"LIVE")
```

**To count total links submitted:**
```
=COUNTA(B:B)-1  [Minus 1 for header]
```

## RED FLAGS (If this happens, adjust strategy)

```
❌ More rejections than approvals → Improve description
❌ Slow press response → Improve angle/pitch
❌ Low engagement on LinkedIn/Reddit → Better headlines, more value
❌ No link growth after 4 weeks → Shift to content creation
❌ Too time-consuming → Automate submissions with templates
```
