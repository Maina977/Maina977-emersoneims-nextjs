## PHASE 3 CONTENT RULES

### Blog Posts: Verified Case Studies Only

**Format:**
```
Title: "[Real Category] Success: How [Anonymized Company] Achieved [Specific Metric]"

Problem: [Industry-standard challenge]
Solution: [Our approach/technology]
Result: [Quantified outcome from actual customer]
Lesson: [Takeaway applicable across industry]

Example Framework:
"A leading mining operation in East Africa faced typical challenges with generator reliability. 
We implemented [specific solution]. The customer reported improved uptime and reduced fuel costs. 
Results: ~50-70% fuel cost reduction is typical for similar implementations."
```

**Requirements:**
- ✅ Anonymize company name OR get written permission
- ✅ Quantify with "typical", "achieved", "reported" (not "guaranteed")
- ✅ Add: "Results vary based on facility size, existing infrastructure, and utilization"
- ✅ Cite industry data sources (World Bank, IEA, country statistics)

## DEFENSIBILITY TEST

**Before publishing ANY content, ask:**

1. ✅ **Verification:** Can we prove this with documentation?
2. ✅ **Permission:** Do we have customer's written consent?
3. ✅ **Honesty:** Would we say this under oath in court?
4. ✅ **Range:** Is this a guarantee or a typical outcome?
5. ✅ **Source:** Where did this number come from?

**If ANY answer is weak → revise or remove.**
